Kiến Trúc Kỹ Thuật Đạt Chuẩn Công Nghệ Cố Định

🐘 PHP 8.x REST API Kiến trúc hướng Module (`backend//.php`), sử dụng PDO Prepared Statements 100% chống SQL Injection.
🗄️ MySQL Database Database `canteen_management` với 22 bảng hoàn chỉnh, foreign key constraints và quản lý transaction ACID an toàn.
🔐 JWT & Password Hash Mã hóa mật khẩu bằng `password_hash()` BCRYPT an toàn. Token JWT xác thực và phân quyền theo Role server-side.
⚡ Modern Vanilla Frontend HTML5 + CSS3 + ES6+ JavaScript, Fetch API tập trung qua `api.js`, hỗ trợ Dark Mode và Responsive đa nền tảng.
